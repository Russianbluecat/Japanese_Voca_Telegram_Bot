# 텔레그램 일본어 단어 퀴즈봇

매일 밤 9시(한국시간)에 텔레그램으로 일본어 단어 4지선다 퀴즈 5문제를 보내주는 봇입니다.
구글시트(Raw_Data 탭)의 데이터를 사용합니다.

## 준비물 (이미 완료하셨다면 건너뛰세요)
- 텔레그램 봇 토큰
- 텔레그램 chat_id
- GitHub 계정

## 설치 순서

### 1. GitHub 저장소 만들기
1. https://github.com 에서 새 저장소(Repository)를 만듭니다.
2. **Public(공개)**으로 만들어주세요. (무료 계정에서 스케줄 자동 실행이 되려면 public repo여야 합니다.
   토큰은 코드에 직접 들어가지 않고 아래 3번의 "Secrets"에 안전하게 저장되므로, public이어도 노출되지 않습니다.)
3. 이 폴더 안의 모든 파일(quiz_bot.py, requirements.txt, .github/workflows/quiz.yml)을
   그 저장소에 그대로 업로드합니다. (GitHub 웹사이트의 "Add file → Upload files" 기능을 쓰면 됩니다.
   이때 `.github/workflows/quiz.yml` 파일의 폴더 구조가 그대로 유지되어야 합니다.)

### 2. GitHub Secrets 등록 (토큰을 안전하게 저장하는 곳)
1. 저장소 페이지에서 **Settings → Secrets and variables → Actions** 로 이동합니다.
2. "New repository secret" 버튼을 눌러 아래 2개를 각각 등록합니다.
   - 이름: `TELEGRAM_BOT_TOKEN`   값: (내 봇 토큰, 예: 8845974312:AAECZlTjTgh5bl4wcL-vH0mMtd_enOJM-A0)
   - 이름: `TELEGRAM_CHAT_IDS`    값: (퀴즈를 받을 사람들의 chat_id를 콤마로 구분해서 나열)
     - 나 혼자 쓸 경우: `79372278`
     - 여러 명이 쓸 경우: `79372278,123456789,987654321`

#### 다른 사람을 추가하려면?
1. 그 사람이 먼저 `t.me/Japanese_Voca_bot` 을 열어 "Start"를 누르고, 아무 메시지나 한 번 보냅니다.
   (봇이 먼저 말을 걸 수 없고, 상대가 먼저 말을 걸어야 텔레그램이 채팅을 인식하기 때문입니다.)
2. 본인이 했던 것과 같은 방법으로, 그 사람의 chat_id를 알아냅니다:
   `https://api.telegram.org/bot<토큰>/getUpdates` 를 열어서 새로 추가된 `chat`:`id` 값을 확인합니다.
3. `TELEGRAM_CHAT_IDS` Secret 값에 콤마로 이어붙여 업데이트합니다. (예: `79372278,새로알아낸id`)

#### 등록된 사람이 채팅방을 나가거나 봇을 차단하면?
- 그 사람에게는 더 이상 퀴즈 메시지가 가지 않습니다. (텔레그램이 전송 자체를 막기 때문에 당연한 동작입니다.)
- 코드에는 이런 경우를 대비한 안전장치가 들어 있어서, **그 사람 한 명만 조용히 건너뛰고 다른 사람들의 퀴즈 진행에는 전혀 영향을 주지 않습니다.**
- 다만 별도로 조치하지 않으면, 매일 그 사람에게 "보내기 시도" 자체는 계속 발생합니다 (실패로 끝날 뿐 오류는 아님).
  완전히 목록에서 빼고 싶다면 `TELEGRAM_CHAT_IDS` Secret 값에서 그 사람의 chat_id를 지워주시면 됩니다.
- 나중에 그 사람이 다시 봇을 차단 해제하고 대화를 재개하고 싶어하면, 위 "다른 사람을 추가하려면?" 순서를 다시 따르면 됩니다 (chat_id는 보통 동일하게 유지됩니다).

### 3. 동작 테스트
1. 저장소 페이지에서 **Actions** 탭으로 이동합니다.
2. "Daily Japanese Quiz" 워크플로우를 선택하고, 오른쪽의 **Run workflow** 버튼을 눌러 수동 실행해봅니다.
3. 몇 초~몇 분 뒤, 텔레그램 봇(Japanese_Voca_bot)이 문제를 보내는지 확인합니다.
4. 버튼을 눌러 정답/오답 피드백이 오는지, 5문제 후 총점이 나오는지 확인합니다.

### 4. 자동 스케줄 확인
- 별도 설정 없이 매일 한국시간 밤 9시(UTC 12:00)에 자동으로 실행됩니다.
- `.github/workflows/quiz.yml` 안의 `cron: "0 12 * * *"` 부분이 스케줄입니다.
  시간을 바꾸고 싶으면 이 값을 수정하면 됩니다. (예: 밤 10시로 바꾸려면 `"0 13 * * *"`)

## 참고 사항
- 구글시트는 "링크가 있는 모든 사용자 - 뷰어"로 공유되어 있어야 코드가 데이터를 읽을 수 있습니다.
- 문제당 답변 대기시간은 10분입니다 (quiz_bot.py의 ANSWER_TIMEOUT_SEC 값으로 조절 가능).
- 시간 내에 응답하지 않으면 오답 처리되고 다음 문제로 넘어갑니다.
- 매일 실행 시간은 GitHub Actions 무료 사용량(월 2,000분, public repo는 무제한) 안에서 충분히 커버됩니다.
